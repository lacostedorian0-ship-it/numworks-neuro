# GEO DASH N0120 — reconstruction C++

Projet de jeu pour NumWorks N0120 / Epsilon, reconstruit à partir des fonctionnalités décrites.

Commandes : Haut/Bas pour naviguer, Gauche/Droite pour changer niveau ou skin, OK pour valider/sauter, Back pour retour, Pi + 0 pour les cheats.

Fonctions : 5 niveaux, 5 skins et 6 cheats. Ce projet est une reconstruction, pas une conversion exacte du script Python original. La compilation doit encore être validée.
